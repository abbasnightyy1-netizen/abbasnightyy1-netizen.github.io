## Privacy Policy

This Privacy Policy explains what data the Tokyo Community Bot ("the Bot," "we," "us") collects when it operates on a Discord server, how it is used, and how it is stored. By adding or using the Bot, you agree to the practices described here.

### 1. Data We Collect
The Bot only collects data necessary to provide its features. We do not collect data for advertising or sell any data to third parties.

| Category | Examples |
|---|---|
| Identifiers | Discord user IDs, server (guild) IDs, channel IDs, role IDs |
| Command usage | Which slash commands are run, when, and by whom, for functionality and rate-limiting |
| Moderation & logs | Moderation actions (warnings, mutes, bans), automod triggers, and server event logs (joins/leaves, edits, deletions) as configured by server staff |
| Tickets & applications | Ticket content and staff application responses submitted by users through the Bot's ticketing and application systems |
| Games & activity | Game scores, participation, and related stats for the Bot's games features |
| Message content | Only where required for a specific feature to function (e.g. automod scanning, ticket transcripts) — not stored or read outside that purpose |

### 2. How We Use Data
- To operate core features: moderation, logging, automod, ticketing, staff applications, and games.
- To enforce cooldowns, permissions, and prevent abuse of commands.
- To let server staff review moderation history and logged events for their own server.

### 3. Data Storage
Data is stored in a local database associated with the Bot's hosting infrastructure. Data is retained only as long as needed for the features above, or until a server removes the Bot / requests deletion, or a user's data is deleted per Section 5.

### 4. Data Sharing
We do not sell or share collected data with third parties. Data collected on a given server (e.g. moderation logs, tickets) is visible only to that server's authorized staff through the Bot's own commands, and to us for the purpose of operating and maintaining the Bot.
